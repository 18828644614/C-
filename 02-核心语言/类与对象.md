# 类与对象

## 学习目标
- [ ] 理解类、对象、成员变量和成员函数之间的关系。
- [ ] 使用 `public`、`private` 和 `protected` 设计清晰的访问边界。
- [ ] 能在类内、类外声明和定义成员函数，并正确使用 `const` 成员函数。
- [ ] 掌握对象、对象指针和对象引用的创建与访问方式。
- [ ] 理解静态成员、`this` 指针和友元的基本用途及限制。
- [ ] 用封装维护对象的不变量，识别类与对象代码中的常见错误。
- [ ] 在 Windows 上使用 MSVC 或 MinGW-w64 编译并运行示例。

## 要点

## 1. 类和对象：设计图与具体实体

在 C++ 中，**类（class）**是一种由程序员定义的类型。它把数据和操作这些数据的函数组织在一起；**对象（object）**则是这个类型的一个具体实例。

可以用“设计图”和“房子”来类比：类描述“应该有哪些部分、能做什么”，对象才是真正占用内存、保存具体数据的实体。例如，`Student` 类可以规定每名学生都有姓名和学号，也能执行自我介绍；小王和小李则是两个不同的 `Student` 对象，各自保存自己的姓名和学号。

类中通常包含两类成员：

- **数据成员（成员变量）**：描述对象当前的状态，例如姓名、年龄、余额。
- **成员函数**：描述对象能够执行的行为，例如打印信息、存款、修改年龄。

~~~cpp
class Student {
public:
    void introduce() const; // 成员函数：描述行为

private:
    int id_ = 0;             // 数据成员：描述状态
};                          // 类定义后必须有分号
~~~

类定义本身主要描述类型的结构，不会因为写出 `class Student` 就自动创建一个学生对象。创建对象后，成员变量才有属于该对象的存储空间：

~~~cpp
Student alice;  // alice 是一个 Student 对象
Student bob;    // bob 是另一个 Student 对象，和 alice 互不相同
~~~

如果类中有 `std::string`、`std::vector` 等成员，它们也会成为对象的一部分。对象销毁时，这些成员会自动销毁；构造函数、析构函数和完整生命周期会在[[构造函数与析构函数]]中详细讨论。

## 2. 定义一个类：访问权限与封装

### 2.1 `public`、`private` 和 `protected`

访问权限决定“哪些代码可以直接使用成员”，不是决定成员是否存在于对象中。

| 权限 | 类的成员函数 | 派生类成员函数 | 类外代码 |
| --- | --- | --- | --- |
| `public` | 可以 | 可以 | 可以 |
| `protected` | 可以 | 可以 | 不可以 |
| `private` | 可以 | 不可以直接访问 | 不可以 |

`public` 部分是类对外提供的接口；`private` 部分是实现细节。把数据设为 `private`，再通过成员函数检查和修改，是**封装（encapsulation）**的基本做法。这样可以避免调用者把对象改成非法状态。

~~~cpp
#include <iostream>
#include <string>
#include <utility>

class BankAccount {
public:
    explicit BankAccount(std::string owner, double initial_balance = 0.0)
        : owner_(std::move(owner)), balance_(initial_balance) {}

    double balance() const { return balance_; }

    bool deposit(double amount) {
        if (amount <= 0.0) { // 不接受零或负数，维护余额规则
            return false;
        }
        balance_ += amount;
        return true;
    }

private:
    std::string owner_; // 类外不能直接 account.balance_;
    double balance_;
};
~~~

调用者只能通过 `deposit` 存款，类可以在一个地方统一检查金额。`private` 并不表示“永远不能访问”：类自己的成员函数可以访问它，后文介绍的友元也可以访问，但应谨慎使用友元。

### 2.2 `class` 与 `struct` 的区别

`class` 和 `struct` 都能包含数据、函数、构造函数和继承，主要区别是默认访问权限：

- `class` 中，未写权限标签的成员默认为 `private`。
- `struct` 中，未写权限标签的成员默认为 `public`。

~~~cpp
class PrivateByDefault {
    int value = 1; // private，类外不能直接访问
};

struct PublicByDefault {
    int value = 1; // public，类外可以直接访问
};
~~~

这不是“`struct` 不能有函数”或“`class` 才能封装”。工程中常用 `struct` 表示简单的数据聚合，用 `class` 表示需要维护不变量和行为的类型；真正的规则仍由显式写出的访问标签决定。

### 2.3 类定义后的分号与前向声明

类定义的右花括号后必须写分号：`class A {};`。忘记分号会导致编译器在后续代码位置报错，错误位置看起来可能与类定义无关。

只需要声明“有这样一个类”时，可以使用前向声明：

~~~cpp
class Window;              // 前向声明
void show(const Window&);  // 可以声明指针、引用相关接口
// Window w;               // 错误：此处还不知道 Window 的完整大小和成员
~~~

前向声明常用于减少头文件依赖；真正创建对象或访问成员前，必须包含完整的类定义。

## 3. 成员函数：类的行为

### 3.1 类内定义与类外定义

成员函数可以直接写在类定义中，也可以只在类中声明、在类外定义。类外定义时必须使用**作用域限定符 `类名::`**：

~~~cpp
#include <string>
#include <utility>

class Student {
public:
    void set_name(std::string name); // 这里只声明
    const std::string& name() const;  // const 成员函数

private:
    std::string name_;
};

void Student::set_name(std::string name) { // 类外定义不能漏掉 Student::
    name_ = std::move(name);
}

const std::string& Student::name() const {
    return name_;
}
~~~

在头文件中直接定义的短成员函数通常隐含 `inline` 属性；如果把普通非 `inline` 函数定义复制到多个源文件，链接阶段可能出现“重复定义”。实际项目一般把类声明放在 `.h`/`.hpp`，把较长定义放在 `.cpp`。

### 3.2 `const` 成员函数

成员函数参数列表后的 `const` 表示：调用该函数不会修改当前对象的非 `mutable` 状态。它既是对读者的承诺，也是编译器的检查：

~~~cpp
class Temperature {
public:
    explicit Temperature(double celsius) : celsius_(celsius) {}

    double celsius() const { return celsius_; } // 只读操作
    void set_celsius(double value) { celsius_ = value; } // 会修改对象

private:
    double celsius_;
};

const Temperature room(22.5);
room.celsius();          // 正确：const 对象可调用 const 成员函数
// room.set_celsius(23); // 错误：不能通过 const 对象调用非 const 函数
~~~

如果一个函数只读取数据，应尽量声明为 `const`，否则 `const` 对象无法使用它。`const` 不会复制对象，也不代表对象一定放在只读内存中；它是编译器层面的修改限制。

### 3.3 函数重载与成员函数调用

同一个类可以有同名但参数列表不同的成员函数，这叫重载。返回类型不能单独用来区分重载：

~~~cpp
class Printer {
public:
    void print(int value) const;
    void print(const char* text) const;
    // int print(int value) const; // 错误：仅返回类型不同不构成重载
};
~~~

通过对象调用成员函数时，写成 `object.function()`；通过指针调用时，写成 `pointer->function()`。`p->f()` 等价于 `(*p).f()`，但前者更简洁。指针必须指向有效对象，不能对 `nullptr` 使用 `->`。

## 4. 创建和使用对象

### 4.1 自动对象、静态对象与动态对象

初学时最常见的是自动对象：

~~~cpp
void work() {
    Student local; // 进入作用域时创建，离开作用域时自动销毁
}
~~~

命名空间作用域的对象和 `static` 局部对象具有更长的生命周期。动态对象由 `new` 创建、由 `delete` 销毁：

~~~cpp
Student* p = new Student{};
delete p;
p = nullptr; // 释放后不再使用悬空指针
~~~

裸 `new/delete` 容易导致忘记释放、重复释放和异常路径泄漏。现代 C++ 中优先使用自动对象、`std::vector`、`std::string` 和智能指针；动态对象的生命周期与 RAII 会在[[对象生命周期与RAII]]和[[智能指针]]中展开。

### 4.2 对象、引用和指针的区别

~~~cpp
Student student;
Student& ref = student;   // 引用是同一对象的别名，必须初始化，不能改绑
Student* ptr = &student;  // 指针保存地址，可以为空，也可以改为指向别处

ref.set_name("小明");
ptr->set_name("小红");   // -> 访问指针所指对象
student.set_name("小刚"); // . 访问对象
~~~

引用通常用于表达“这里必须有一个对象”；指针适合表达“可能没有对象”或需要改变指向的场景。它们默认都不拥有对象，不能在对象已经销毁后继续使用。

### 4.3 初始化和赋值不是一回事

~~~cpp
Student first;       // 初始化：first 从不存在变为存在
Student second = first; // 拷贝初始化：创建 second
second = first;      // 赋值：second 已经存在，替换其状态
~~~

初始化会调用构造函数，赋值会调用赋值运算符。成员初始化列表、拷贝/移动构造以及析构顺序请参见[[构造函数与析构函数]]。

## 5. `this` 指针：当前对象的地址

每个非静态成员函数都隐含接收一个指向当前对象的指针，名字就是 `this`。因此，`value_` 通常等价于 `this->value_`。当参数名和成员名相同时，`this` 可以消除歧义：

~~~cpp
class Point {
public:
    void set_x(int x) {
        this->x = x; // 左侧是成员，右侧是参数
    }

    Point& move_by(int dx, int dy) {
        x += dx;
        y += dy;
        return *this; // 返回当前对象本身，支持链式调用
    }

private:
    int x = 0;
    int y = 0;
};

Point point;
point.move_by(1, 2).move_by(3, 4);
~~~

`this` 是一个不可重新指向的指针（在普通成员函数中类型近似为 `Point* const`，在 `const` 成员函数中近似为 `const Point* const`）。静态成员函数没有 `this`，因为它不属于某个具体对象。

## 6. 静态成员：属于类，而不是某个对象

非静态成员每个对象各有一份；静态成员由整个类共享一份。静态成员函数可以用 `类名::函数名()` 调用，不需要对象：

~~~cpp
class Session {
public:
    Session() { ++active_count_; }
    ~Session() { --active_count_; }

    static int active_count() { return active_count_; }

private:
    inline static int active_count_ = 0; // C++17：类内定义一次即可
};

int before = Session::active_count();
{
    Session a;
    Session b;
    // Session::active_count() == 2
}
// Session::active_count() == 0
~~~

静态成员函数不能直接访问 `name_` 这类非静态成员，也不能使用 `this`，因为调用它时可能根本没有任何对象。C++17 以前，静态数据成员通常需要在一个 `.cpp` 文件中再提供类外定义：`int Session::active_count_ = 0;`；使用 `inline static` 可避免这一额外定义。

## 7. 友元：有控制地开放访问

`friend` 可以让指定的函数或类访问当前类的 `private`/`protected` 成员：

~~~cpp
class Box {
public:
    explicit Box(int value) : value_(value) {}

    friend int read_value(const Box& box); // 声明友元函数

private:
    int value_;
};

int read_value(const Box& box) {
    return box.value_; // 虽然不是成员函数，但因 friend 可访问 private
}
~~~

友元关系不是继承关系，也不会自动传递：`Box` 是 `read_value` 的友元，不代表 `read_value` 的调用者也能访问 `Box` 的私有数据。友元适合实现紧密协作的运算符或序列化函数，但过度使用会破坏封装；能通过公开接口完成时，优先使用公开接口。

## 8. 用封装维护不变量：设计一个可靠的类

**不变量（invariant）**是对象在可观察状态下始终应该满足的条件。例如银行账户余额不能为负、矩形宽高必须为正。一个好的类通常遵循以下思路：

1. 构造对象时建立合法初始状态。
2. 将容易被随意修改的数据设为 `private`。
3. 通过有意义的操作修改状态，并在操作内部检查参数。
4. 让只读查询函数使用 `const`，减少无意修改。
5. 不为了“字段看起来完整”而机械地提供所有 setter；公开接口应表达业务规则。

例如，矩形不允许出现负宽度：

~~~cpp
#include <stdexcept>

class Rectangle {
public:
    Rectangle(double width, double height)
        : width_(width), height_(height) {
        if (width <= 0.0 || height <= 0.0) {
            throw std::invalid_argument("宽度和高度必须为正数");
        }
    }

    double area() const { return width_ * height_; }
    double width() const { return width_; }
    double height() const { return height_; }

private:
    double width_;
    double height_;
};
~~~

这里先用成员初始化列表建立成员值，再在构造函数体中校验参数。抛出异常表示无法建立合法对象，调用方应捕获或让异常继续向上处理；成员初始化列表的规则见[[构造函数与析构函数]]。

## 9. 常见错误与排查清单

1. **忘记类定义后的分号**：`class A {}` 后必须写 `;`。
2. **漏写作用域限定符**：类外定义应写 `void Student::set_name(...)`，不能只写 `void set_name(...)`。
3. **把私有成员当成公开成员访问**：`account.balance_` 会编译错误，应提供受控的成员函数。
4. **混淆 `.` 和 `->`**：对象用 `.`，对象指针用 `->`；不要对空指针解引用。
5. **忘记 `const`**：只读函数未声明 `const`，导致 `const` 对象无法调用。
6. **以为 `const` 成员函数什么都不能改**：它不能改对象的普通状态，但可以修改 `mutable` 成员；更重要的是，它不保证被调用对象本身位于只读内存。
7. **返回局部对象成员的引用或指针**：局部对象离开函数后销毁，返回的引用/指针会悬空；可按值返回，或返回由调用方拥有的对象。
8. **静态成员函数访问非静态成员**：静态函数没有 `this`，必须通过对象参数或改为普通成员函数。
9. **用地址判断对象是否相等**：`&a == &b` 只比较两个对象是否是同一存储位置，不是比较内容；应定义 `operator==` 或逐字段比较。
10. **过早使用裸 `new/delete`**：优先使用自动对象和 RAII 类型，避免手工管理所有权。
11. **用 `memcmp` 比较类对象**：填充字节、指针和资源句柄会使按内存比较不可靠；应比较有意义的成员。

## 示例与实践

### 1. 完整可运行示例：学生类、`const`、对象指针与静态成员

下面程序综合演示了访问控制、类外定义成员函数、`const`、`this`、对象与指针的访问方式，以及 C++17 的 `inline static`。程序只使用标准库，可在 Windows 的 MSVC、MinGW-w64 或其他 C++17 编译器中运行。

~~~cpp
#include <iostream>
#include <stdexcept>
#include <string>
#include <utility>

class Student {
public:
    Student(int id, std::string name)
        : id_(id), name_(std::move(name)) {
        if (id <= 0 || name_.empty()) {
            throw std::invalid_argument("学号必须为正数，姓名不能为空");
        }
        ++object_count_;
    }

    Student(const Student& other)
        : id_(other.id_), name_(other.name_) {
        ++object_count_; // 拷贝出一个新对象，也要计入活动对象数
    }

    ~Student() { --object_count_; }

    int id() const { return id_; }
    const std::string& name() const { return name_; }

    void rename(std::string new_name) {
        if (new_name.empty()) {
            throw std::invalid_argument("姓名不能为空");
        }
        name_ = std::move(new_name);
    }

    void print() const {
        std::cout << "学号：" << id_ << "，姓名：" << name_ << '\n';
    }

    static int object_count() { return object_count_; }

private:
    int id_;
    std::string name_;
    inline static int object_count_ = 0; // 所有 Student 对象共享一份
};

int main() {
    try {
        std::cout << "创建前对象数：" << Student::object_count() << '\n';

        Student alice(1001, "小王");
        const Student bob(1002, "小李");

        alice.print();       // 对象使用 .
        bob.print();         // const 对象可以调用 const 成员函数

        Student* pointer = &alice;
        pointer->rename("小王（已改名）"); // 指针使用 ->
        pointer->print();

        std::cout << "当前对象数：" << Student::object_count() << '\n';
        // Student bad(0, ""); // 取消注释会抛出异常，非法对象不会创建成功
    } catch (const std::exception& ex) {
        std::cerr << "发生错误：" << ex.what() << '\n';
    }

    std::cout << "离开作用域后对象数：" << Student::object_count() << '\n';
}
~~~

在 Visual Studio Developer PowerShell 中：

~~~powershell
cl /std:c++17 /W4 /EHsc class_object_demo.cpp /Fe:class_object_demo.exe
.\class_object_demo.exe
~~~

在已配置 MinGW-w64 的 PowerShell 中：

~~~powershell
g++ -std=c++17 -Wall -Wextra -pedantic class_object_demo.cpp -o class_object_demo.exe
.\class_object_demo.exe
~~~

### 2. 完整可运行示例：使用组合表达“拥有”关系

继承与组合不要混用。汽车“拥有”发动机，因此把 `Engine` 作为 `Car` 的成员更自然：

~~~cpp
#include <iostream>

class Engine {
public:
    void start() const { std::cout << "发动机启动\n"; }
};

class Car {
public:
    void start() const {
        engine_.start(); // Car 通过成员对象复用 Engine 的能力
        std::cout << "汽车出发\n";
    }

private:
    Engine engine_; // Car has-a Engine
};

int main() {
    Car car;
    car.start();
}
~~~

如果一个类型必须能在需要另一个类型的地方被替代，才考虑 `public` 继承（例如“狗是一种动物”）；如果只是复用功能或表示组成部分，优先考虑组合。继承、多态和对象切片请参见[[继承与多态]]。

4. 把 `Car` 的 `Engine` 改成指针，思考谁拥有发动机、空指针如何处理，再改回成员对象。
5. 写一个接收 `const Rectangle&` 的函数，尝试调用非 `const` 成员函数并解释编译错误。
