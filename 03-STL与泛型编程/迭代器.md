# 迭代器

## 学习目标

- [ ] 理解迭代器和“指向元素的通道”这一核心模型。
- [ ] 能正确使用 `begin()`、`end()`、解引用、递增和区间遍历。
- [ ] 能区分输入、输出、前向、双向和随机访问迭代器。
- [ ] 会把迭代器传给标准算法，并理解算法为什么不依赖具体容器。
- [ ] 能识别 `const_iterator`、反向迭代器和迭代器失效等常见问题。

## 要点

### 1. 迭代器到底是什么

初学者可以先把迭代器理解成一种**访问容器元素的通用工具**。它有点像指针：

- 可以通过 `*it` 访问它“当前指向”的元素；
- 可以通过 `++it` 移动到下一个元素；
- 两个迭代器通常用来表示一段范围的开始和结束。

但迭代器不一定是真正的内存地址。`vector` 的迭代器通常很像指针；`list` 的迭代器则可能内部保存一个链表节点指针；`map` 的迭代器还要负责按照树结构移动。它们的外观相似，是因为标准库规定了共同的操作。

可以用“书签”来类比：容器是一排书，迭代器是夹在某本书前面的书签。`*it` 表示阅读书签所在的书，`++it` 表示把书签向后移动。迭代器只能在它所属的容器中使用，不能拿 A 容器的迭代器去访问 B 容器。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers{10, 20, 30};

    auto it = numbers.begin(); // it 指向第一个元素 10
    std::cout << *it << '\n';   // *it：读取迭代器当前指向的元素，输出 10

    ++it;                      // 迭代器向后移动一个位置
    std::cout << *it << '\n';  // 现在 it 指向 20，输出 20
}
```

`auto` 让编译器推导迭代器的具体类型。不同容器的迭代器类型通常不同，直接写出完整类型既长又容易写错，所以实际代码中常写 `auto`。

### 2. `begin()`、`end()` 和半开区间

容器常用下面两个成员函数表示一段范围：

- `begin()`：指向第一个元素；
- `end()`：指向**最后一个元素之后**的位置，也叫“尾后迭代器”。

`end()` 不是最后一个元素，不能写 `*container.end()`。它只是一个停止标记，用来表示“已经走完了所有元素”。

标准库采用 `[begin, end)` 的**半开区间**约定：包含 `begin`，不包含 `end`。这个约定看起来有点特殊，但有三个好处：

1. 空容器的范围仍然成立，此时 `begin() == end()`；
2. 元素个数正好等于从 `begin` 走到 `end` 的步数；
3. 多个相邻范围可以自然拼接，例如 `[first, middle)` 和 `[middle, last)`。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers{10, 20, 30};

    // 只要 it 还没有到 end，就说明它指向一个有效元素。
    for (auto it = numbers.begin(); it != numbers.end(); ++it) {
        std::cout << *it << ' '; // 输出：10 20 30
    }

    // numbers.end() 不能解引用：它不代表 30，而是 30 后面的位置。
    // std::cout << *numbers.end(); // 错误：未定义行为
}
```

范围 `for` 循环本质上也依赖 `begin()`、`end()` 和迭代器，只是把样板代码隐藏起来：

```cpp
for (int value : numbers) {
    std::cout << value << ' ';
}

// 近似等价于：
for (auto it = numbers.begin(); it != numbers.end(); ++it) {
    int value = *it;
    std::cout << value << ' ';
}
```

### 3. 迭代器的基本操作

| 写法 | 含义 | 新手注意点 |
| --- | --- | --- |
| `*it` | 访问当前元素 | `it` 必须指向有效元素，不能是 `end()` |
| `it->member` | 访问当前元素的成员 | 等价于 `(*it).member`，常用于 `vector<struct>` 或 `map` |
| `++it` | 移到下一个位置 | 到达 `end()` 后不能继续递增 |
| `--it` | 移到上一个位置 | 只有双向及更强的迭代器支持 |
| `it1 == it2` | 判断是否在同一位置 | 两个迭代器必须属于同一容器或同一范围 |
| `it + n` | 向后移动 `n` 步 | 只有随机访问迭代器支持 |
| `it1 - it2` | 计算两个位置的距离 | 只有随机访问迭代器支持 |
| `it[n]` | 访问当前位置后第 `n` 个元素 | 只有随机访问迭代器支持 |

前置递增 `++it` 通常比后置递增 `it++` 更推荐：前置递增直接移动当前迭代器，后置递增需要先保存旧值。对 `vector` 影响很小，但对复杂迭代器可能有额外开销。

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> scores{{"Alice", 90}, {"Bob", 80}};

    for (auto it = scores.begin(); it != scores.end(); ++it) {
        // map 的元素是 pair：first 是键，second 是值。
        std::cout << it->first << ": " << it->second << '\n';
    }
}
```

### 4. 可写迭代器、`const_iterator` 和 `cbegin()`

如果容器对象不是 `const`，`begin()` 通常返回可写迭代器，可以修改元素：

```cpp
std::vector<int> numbers{1, 2, 3};

for (auto it = numbers.begin(); it != numbers.end(); ++it) {
    *it *= 2; // 修改元素，numbers 变成 {2, 4, 6}
}
```

只读遍历时，推荐使用 `cbegin()` 和 `cend()`，它们返回 `const_iterator`。通过它不能修改元素，可以防止意外改数据：

```cpp
const std::vector<int> numbers{1, 2, 3};

for (auto it = numbers.cbegin(); it != numbers.cend(); ++it) {
    std::cout << *it << ' '; // 可以读取
    // *it = 10;              // 错误：const_iterator 不允许修改
}
```

即使容器本身不是 `const`，也可以主动使用 `cbegin()`：

```cpp
std::vector<int> numbers{1, 2, 3};
auto it = numbers.cbegin(); // 明确表达“这里只读”
```

### 5. 五类迭代器：能力逐级增加

迭代器类别描述的是“一个迭代器保证支持哪些操作”，不是容器名称。能力越强，可以使用的算法通常越多。

| 类别 | 能力 | 典型例子 |
| --- | --- | --- |
| 输入迭代器（input） | 读取元素、向前走；通常只能单遍读取 | `std::istream_iterator` |
| 输出迭代器（output） | 向当前位置写入、向前走；通常只能单遍写入 | `std::ostream_iterator` |
| 前向迭代器（forward） | 可读写、只能向前走，并可多次遍历 | `forward_list`、`unordered_map` |
| 双向迭代器（bidirectional） | 在前向基础上增加 `--it` | `list`、`map`、`set` |
| 随机访问迭代器（random access） | 支持 `+`、`-`、比较距离和下标 | `vector`、`array`、`deque` |

C++20 还引入了更精确的迭代器概念（iterator concepts），例如 `std::random_access_iterator`。传统教材常把迭代器分成五类；理解“算法需要最低能力”更重要：

- `std::find` 只需要能够读取并向前移动，因此链表也能使用；
- `std::reverse` 需要双向移动，因此不能直接用于 `forward_list`；
- `std::sort` 需要随机访问，因此不能直接用于 `list`。

```cpp
#include <algorithm>
#include <forward_list>
#include <list>
#include <vector>

int main() {
    std::vector<int> values{3, 1, 2};
    std::sort(values.begin(), values.end()); // vector 提供随机访问迭代器

    std::list<int> linked{3, 1, 2};
    linked.sort(); // list 使用自己的成员函数排序

    std::forward_list<int> one_way{3, 1, 2};
    one_way.reverse(); // forward_list 也提供适合自身结构的成员函数
    // std::sort(one_way.begin(), one_way.end()); // 错误：sort 要求随机访问迭代器
}
```

### 6. 迭代器与标准算法：算法不关心容器是什么

标准算法通常接收两个迭代器，表示要处理的范围：

```cpp
std::sort(numbers.begin(), numbers.end());
```

算法只依赖迭代器提供的能力，而不是依赖 `vector` 的成员函数。因此同一个 `std::find` 可以处理 `vector`、`list`、数组，甚至输入流。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers{10, 20, 30, 40};

    auto it = std::find(numbers.begin(), numbers.end(), 30);

    if (it != numbers.end()) {
        // 找到时，it 指向值为 30 的元素。
        std::cout << "找到：" << *it << '\n';
        std::cout << "下标：" << (it - numbers.begin()) << '\n';
    } else {
        // 找不到时，find 返回 end()。
        std::cout << "没有找到\n";
    }
}
```

注意：`it - numbers.begin()` 只适用于随机访问迭代器。若容器是 `list`，应使用 `std::distance(numbers.begin(), it)`；它对链表需要逐个移动，复杂度是 `O(n)`。

```cpp
#include <algorithm>
#include <iterator>
#include <list>

std::list<int> numbers{10, 20, 30};
auto it = std::find(numbers.begin(), numbers.end(), 30);
auto position = std::distance(numbers.begin(), it); // 位置为 2，但需要线性遍历
```

### 7. 反向迭代器：从尾部向头部遍历

支持双向移动的容器通常有 `rbegin()` 和 `rend()`：

- `rbegin()` 指向最后一个元素；
- `rend()` 表示第一个元素之前的位置。

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers{1, 2, 3};

    for (auto it = numbers.rbegin(); it != numbers.rend(); ++it) {
        std::cout << *it << ' '; // 输出：3 2 1
    }
}
```

反向迭代器的 `++` 表示“向原容器的前方移动”。它仍然使用 `++it`，但结果是从尾部走向头部。

如果需要把反向迭代器转换为普通迭代器，可使用 `base()`。这里有一个容易出错的偏移：

```cpp
std::vector<int> numbers{10, 20, 30, 40};
auto reverse_it = std::find(numbers.rbegin(), numbers.rend(), 30);

auto normal_it = reverse_it.base();
// normal_it 指向 30 的“后一个位置”（40），不是 30 本身。
// 因为 reverse_iterator 的 base() 总是返回正向位置的下一个位置。
--normal_it; // 现在 normal_it 才指向 30
```

### 8. 迭代器失效：容器变化后要特别小心

迭代器失效意味着：迭代器不再可靠地指向原来的元素。继续解引用失效迭代器是未定义行为，可能崩溃，也可能暂时输出“看起来正常”的结果。

常见规则可以先记成下面这样：

| 容器 | 插入或追加 | 删除 |
| --- | --- | --- |
| `vector` | 扩容时所有迭代器失效；未扩容时，插入位置及其后方失效 | 被删位置及其后方失效 |
| `deque` | 迭代器失效规则较复杂，修改后不要盲用旧迭代器 | 两端和中间删除的影响不同，优先使用返回值 |
| `list` / `forward_list` | 已有元素的迭代器通常保持有效 | 只有被删元素的迭代器失效 |
| `map` / `set` | 插入通常不影响已有迭代器 | 只有被删元素的迭代器失效 |

`vector` 失效的原因是扩容可能把元素搬到一块新内存：旧迭代器仍保存旧地址，所以不能继续使用。

```cpp
#include <vector>

std::vector<int> values{1, 2, 3};
auto it = values.begin();

values.push_back(4); // 可能发生扩容
// std::cout << *it;  // 错误：it 可能已经失效
```

遍历时删除元素，应接住 `erase` 返回的新迭代器：

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> values{1, 2, 3, 4, 5};

    for (auto it = values.begin(); it != values.end();) {
        if (*it % 2 == 0) {
            it = values.erase(it);
            // erase 删除 it 指向的元素，并返回下一个仍然有效的位置。
            // 因此这里不能再写 ++it，否则会跳过一个元素。
        } else {
            ++it; // 没删除时，才手动移动到下一个元素
        }
    }

    for (int value : values) {
        std::cout << value << ' '; // 输出：1 3 5
    }
}
```

### 9. 插入元素时使用返回的迭代器

许多容器操作会返回一个新的迭代器。养成查看返回值的习惯，可以避免重新查找位置，也能更安全地继续操作。

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<int, std::string> users;

    auto [it, inserted] = users.emplace(1, "Alice");
    if (inserted) {
        std::cout << "插入成功：" << it->second << '\n';
    }

    // 如果键 1 已存在，emplace 不会覆盖旧值，inserted 会是 false。
}
```

### 10. C++20 范围（ranges）入门

C++20 的 `<ranges>` 让算法可以直接接收一个容器或范围，减少手写 `begin()` / `end()` 的机会：

```cpp
#include <algorithm>
#include <iostream>
#include <ranges>
#include <vector>

int main() {
    std::vector<int> numbers{3, 1, 2};

    std::ranges::sort(numbers); // 等价于 std::sort(numbers.begin(), numbers.end())

    for (int value : numbers) {
        std::cout << value << ' '; // 输出：1 2 3
    }
}
```

范围并没有让迭代器消失；它只是把“起点、终点和范围约束”组织得更安全、更清晰。理解传统迭代器仍然很重要，因为大量旧代码和 STL 接口仍然直接使用迭代器。

## 常见错误

### 错误 1：解引用 `end()`

```cpp
auto it = numbers.end();
// std::cout << *it; // 错误：end() 是尾后位置，不是最后一个元素
```

如果想访问最后一个元素，应先确认容器非空，再使用 `back()` 或 `--end()`：

```cpp
if (!numbers.empty()) {
    std::cout << numbers.back() << '\n';

    auto last = numbers.end();
    --last; // 先从尾后位置退一步，才得到最后一个元素
    std::cout << *last << '\n';
}
```

### 错误 2：删除后继续递增或解引用旧迭代器

```cpp
// 错误写法：erase 后 it 已经失效，不能再 ++it。
// values.erase(it);
// ++it;
```

应改为 `it = values.erase(it)`，参见上面的安全删除示例。

### 错误 3：保存 `vector` 迭代器后继续扩容

如果需要长期保存位置，可以保存下标（同时确认下标语义仍然有效），或在容器修改后重新调用 `begin()` / `find()` 获取迭代器。`reserve()` 可以减少扩容概率，但不能让所有后续插入都绝对不失效。

### 错误 4：把所有迭代器都当成指针

不能默认所有迭代器都支持 `it + 5`、`it[5]` 或 `it2 - it1`。写泛型代码时，应只使用算法要求的最低能力；对普通使用者来说，优先使用 `++it` 和 `it != end` 最稳妥。

## 示例与实践

### 综合示例：查找、修改和删除

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::vector<std::string> names{"Alice", "Bob", "Cindy", "Bob"};

    // find 返回指向第一个 Bob 的迭代器。
    auto first_bob = std::find(names.begin(), names.end(), "Bob");
    if (first_bob != names.end()) {
        *first_bob = "Bobby"; // 通过可写迭代器修改元素
    }

    // erase-remove idiom：删除所有值为 Bob 的元素。
    auto new_end = std::remove(names.begin(), names.end(), "Bob");
    names.erase(new_end, names.end());

    // cbegin/cend 表示下面只读，不会再修改 names。
    for (auto it = names.cbegin(); it != names.cend(); ++it) {
        std::cout << *it << '\n'; // Alice、Bobby、Cindy
    }
}
```

这个例子串起了几个关键点：算法用迭代器表示范围；查找失败时要和 `end()` 比较；修改需要可写迭代器；删除后不能继续使用旧迭代器；只读遍历可以使用 `cbegin()` 和 `cend()`。

## 练习建议

1. 用普通 `for` 循环（不使用范围 `for`）打印一个 `vector` 的所有元素。
2. 使用 `std::find` 查找一个整数，并输出它距离 `begin()` 的位置。
3. 遍历 `vector`，删除所有奇数，确保使用 `erase` 的返回值。
4. 分别用正向迭代器和反向迭代器打印同一个 `list`。
5. 尝试把 `std::sort` 用在 `list` 上，观察编译错误，再改为 `list.sort()`。
