# 第一章面试题与答案

## 使用说明

本文以面试官视角复习 [[01-基础入门/README]]。重点不是背诵定义，而是能够解释代码为什么这样运行、错误发生在哪个阶段，以及如何选择值、指针、引用和现代标准库工具。

本章覆盖 [[C++概览]]、[[开发环境]]、[[源文件、编译与链接]]、[[基本语法与控制流]]、[[类型、变量与常量]]、[[函数与作用域]]、[[数组、指针与引用]]。

## 一、C++ 基础认知

### 1. C++ 是编译型语言吗？什么叫静态类型？

C++ 通常被称为编译型、静态类型语言。

编译型表示源代码通常先经过编译器转换为目标代码，再链接成可执行文件。静态类型表示变量和表达式的类型通常在编译期确定，编译器会提前检查很多错误。

“编译型”不代表绝对不能解释执行，某些环境也可以通过解释器或 JIT 运行 C++。更准确的说法是：C++ 的主流开发方式是提前编译成本地机器代码。

C++ 支持过程式、面向对象、泛型和函数式等多种范式，可以直接控制内存和系统资源。所谓“零开销抽象”是设计目标，不代表程序一定高效；算法、数据结构、缓存访问和内存分配仍然会决定性能。

### 2. C++ 标准、编译器、标准库、IDE 和 CMake 有什么区别？

- **C++ 标准**：规定语言和标准库应该怎样工作，例如 C++17、C++20。
- **编译器**：把 C++ 源代码转换为目标代码，例如 MSVC、GCC、Clang。
- **标准库**：提供 `std::string`、`std::vector`、`std::cout` 等功能。
- **IDE 或编辑器**：用于编写、导航和调试代码，例如 Visual Studio、VS Code、CLion。
- **构建工具**：管理多个源文件、编译选项和依赖，例如 CMake、MSBuild、Ninja。
- **调试器**：支持断点、单步执行、查看变量和调用栈。

CMake 不是编译器。它通常负责生成或协调底层构建系统，最终仍然由 MSVC、GCC 或 Clang 编译代码。

### 3. 一个 `.cpp` 文件到 `.exe` 通常经历哪些阶段？

通常可以分为：

1. **预处理**：处理 `#include`、宏和条件编译。
2. **编译**：检查 C++ 语法和类型，把源代码翻译为汇编或目标代码。
3. **汇编**：把汇编代码转换为机器指令，生成 `.obj` 或 `.o`。
4. **链接**：把多个目标文件、静态库和运行库组合起来，解析函数和变量符号。
5. **运行**：操作系统加载可执行文件和 DLL，运行时启动代码最终调用 `main`。

常见错误与阶段的对应关系：

- 找不到头文件：通常是预处理阶段错误；
- 缺少分号：通常是编译阶段错误；
- `undefined reference` 或 `unresolved external symbol`：通常是链接阶段错误；
- 缺少 DLL：通常是运行阶段错误；
- 程序输出错误：通常是逻辑错误。

### 4. `#include` 到底做了什么？

`#include` 是预处理指令，可以粗略理解为把目标头文件的内容展开到当前源文件中。

头文件通常不是单独编译的。每个 `.cpp` 文件经过预处理后，会形成一个独立的编译单元，然后分别编译。

这也解释了三个现象：修改头文件后，所有包含它的 `.cpp` 通常都需要重新编译；头文件需要防重复包含；头文件通常放声明，源文件通常放定义。

### 5. 声明和定义有什么区别？

声明告诉编译器“某个实体存在，以及它的类型和使用方式”；定义则真正提供实体的内容，或者为对象分配存储。

```cpp
// 声明
int add(int, int);

// 定义
int add(int a, int b) {
    return a + b;
}

// 调用
int result = add(1, 2);
```

如果只有声明，没有定义，当前文件可能编译成功，但链接时会失败。多文件项目中通常是头文件放声明、源文件放定义、`main.cpp` 包含头文件并调用函数。

### 6. `main` 函数和命令行参数如何工作？

常见形式是：

```cpp
int main(int argc, char* argv[]) {
    return 0;
}
```

其中 `argc` 表示参数个数，`argv` 表示参数数组。`argv[0]` 通常是程序路径，用户传入的第一个参数通常是 `argv[1]`。访问参数前必须检查 `argc`：

```cpp
if (argc > 1) {
    std::cout << argv[1] << '\n';
}
```

`main` 返回的整数会作为程序退出码交给操作系统。通常返回 `0` 表示成功，非零值表示失败。

## 二、基本语法和控制流

### 7. `=`、`==`、`&&`、`&` 分别是什么？

```cpp
a = b;      // 赋值
a == b;     // 判断相等
a && b;     // 逻辑与
a & b;      // 按位与
```

常见错误是：

```cpp
if (x = 5) {
}
```

这会把 `5` 赋值给 `x`，赋值表达式的结果也是 `5`，转换为布尔值后为真。正确写法通常是 `if (x == 5)`。应开启较高警告级别，让编译器帮助发现这类问题。

### 8. 什么是短路求值？

对于内置逻辑运算，`A && B` 在 `A` 为假时不会计算 `B`；`A || B` 在 `A` 为真时不会计算 `B`。

```cpp
if (pointer != nullptr && *pointer == 10) {
}
```

只有指针非空时，右侧解引用才会执行，因此这种写法可以避免空指针解引用。另一方面，短路也可能导致右侧函数根本不执行，不建议把重要副作用隐藏在复杂条件中。

### 9. `if` 和 `switch` 有什么区别？

`if` 适合范围判断、复杂条件和字符串比较；`switch` 适合根据整数、字符或枚举等离散值选择分支。

```cpp
switch (level) {
case 1:
    std::cout << "low";
    break;
case 2:
    std::cout << "high";
    break;
default:
    std::cout << "unknown";
    break;
}
```

`case` 默认不会自动结束。如果缺少 `break`，程序会继续执行后面的 `case`，这叫贯穿（fallthrough）。有意贯穿时应写注释说明。

### 10. `for`、`while`、`do...while` 如何选择？

- `for`：适合循环次数较明确的场景；
- `while`：适合循环次数不确定、先判断条件的场景；
- `do...while`：适合循环体至少执行一次的场景。

范围 `for` 中，`auto value` 会复制元素，`auto& value` 可以修改原元素，`const auto& value` 只读且避免复制大型对象：

```cpp
for (const auto& value : values) {
    std::cout << value << '\n';
}
```

### 11. `break`、`continue` 和 `return` 有什么区别？

- `break`：结束最近一层循环或 `switch`；
- `continue`：跳过本轮循环剩余代码，进入下一轮；
- `return`：直接结束整个当前函数。

在 `for` 循环中，执行 `continue` 后仍然会执行更新表达式；在 `while` 中，如果 `continue` 跳过了计数变量更新，可能造成死循环。

## 三、类型、变量与常量

### 12. 类型不仅决定大小，还决定什么？

类型会影响对象如何解释、允许的操作、运算结果、隐式转换、函数重载选择以及编译器能发现的错误。

```cpp
int a{5};
double b{2.0};
auto result = a / b; // double
```

因此类型不只是“占几个字节”。相同大小的类型也可能有不同的运算规则和语义。

### 13. 初始化和赋值有什么区别？

初始化发生在对象创建时：`int score{80};`。赋值发生在对象已经存在之后：`score = 90;`。

推荐使用花括号初始化，因为列表初始化会阻止很多窄化转换：

```cpp
// int value{3.14}; // 编译错误
int value = 3.14;   // 通常可以编译，但会丢失小数
```

局部变量应尽量在声明时初始化。`int value;` 没有初始化，读取它的值是不安全的；`int value{};` 会初始化为 `0`。

### 14. `const` 和 `constexpr` 有什么区别？

`const` 表示初始化后不能通过该对象修改，但初始值可以运行时才确定：

```cpp
const int value{read_value()};
```

`constexpr` 要求初始化结果可以在编译期确定：

```cpp
constexpr int days_per_week{7};
```

`constexpr` 变量同时具有 `const` 属性。

### 15. 为什么 `5 / 2` 等于 `2` 而不是 `2.5`？

因为两个操作数都是整数，执行的是整数除法：`int result = 5 / 2;`。

让至少一个操作数成为浮点类型，或显式转换即可：

```cpp
double a = 5.0 / 2;
double b = static_cast<double>(5) / 2;
```

`double result = 5 / 2;` 仍然是先算出整数 `2`，再把结果转换为 `double`。

### 16. 有符号整数和无符号整数混合运算有什么风险？

无符号整数不能表示负数，减法可能回绕：

```cpp
unsigned int value{0};
--value; // 得到一个很大的无符号数
```

混合比较也可能出错：

```cpp
int index{-1};
std::size_t size{10};

if (index < size) {
}
```

由于 `size` 是无符号类型，`index` 可能先转换成很大的无符号数，结果和直觉不一致。实际代码中应统一类型，并认真处理边界。

### 17. `enum` 和 `enum class` 有什么区别？

`enum class` 是作用域枚举，枚举项需要通过作用域访问，不容易与其他名字冲突，也不会自动转换成普通整数：

```cpp
enum class Color { red, blue };
Color color{Color::red};
```

如果需要底层整数，应显式转换：`int value = static_cast<int>(color);`。

## 四、函数、作用域与生命周期

### 18. 函数声明、定义、调用分别是什么？

```cpp
int add(int, int);              // 声明

int add(int a, int b) {         // 定义
    return a + b;
}

int result = add(1, 2);         // 调用
```

声明让编译器知道函数存在以及如何调用；定义提供真正实现；调用会执行函数。多文件项目中，声明通常放头文件，定义放源文件。

### 19. 按值、按引用、按指针传参有什么区别？

按值传递得到副本，修改参数不影响调用者：

```cpp
void set_value(int value) {
    value = 10;
}
```

按引用传递使用原对象的别名，函数内修改会影响调用者：

```cpp
void set_value(int& value) {
    value = 10;
}
```

按指针传递地址，可以表示“没有对象”，但使用前要检查空指针：

```cpp
void set_value(int* value) {
    if (value != nullptr) {
        *value = 10;
    }
}
```

常用选择规则：需要独立副本用值传递；需要修改调用者对象用 `T&`；只读且对象较大用 `const T&`；允许没有对象时用 `T*`。

### 20. 为什么不能只通过返回类型重载函数？

下面是不合法的：

```cpp
int get_value(int);
double get_value(int);
```

调用 `get_value(1)` 时，编译器无法仅根据返回类型判断应该调用哪个版本。重载主要依据函数名、参数数量、参数类型和参数顺序，而不是返回类型。

### 21. 默认参数有什么限制？

默认参数必须从最右侧开始连续提供：

```cpp
void connect(const std::string& host, int port = 80);
```

这样既可以调用 `connect("example.com")`，也可以调用 `connect("example.com", 8080)`。不能只给左侧参数默认值而让右侧参数没有默认值。默认值通常只写在一次声明中，常放在头文件声明里。

### 22. 作用域和生命周期有什么区别？

作用域回答“名字在哪里可用”，生命周期回答“对象什么时候存在”。

```cpp
int main() {
    int value{10};
    {
        int inner{20};
    }
    // inner 已经不在作用域内，对象也已销毁
}
```

二者不是同一个概念。局部 `static` 变量的名字只有局部作用域，但对象生命周期会持续到程序结束。

### 23. 函数内的 `static` 和文件级的 `static` 有什么区别？

函数内的 `static` 对象只初始化一次，生命周期持续到程序结束：

```cpp
int next_id() {
    static int id{0};
    return ++id;
}
```

文件级的 `static` 表示内部链接，名字只在当前源文件可见。二者含义不同，必须结合声明所在位置判断。

### 24. 为什么不能返回局部变量的引用或指针？

```cpp
int& get_value() {
    int value{10};
    return value; // 错误：函数返回后 value 已销毁
}
```

函数返回时局部对象已经销毁，返回的引用或指针会悬空，后续使用属于未定义行为。通常应按值返回，现代 C++ 通常会通过返回值优化避免不必要的复制。

## 五、数组、指针与引用

### 25. 数组有什么特点？下标从多少开始？

数组保存一组连续的同类型对象：

```cpp
int values[5]{};
```

元素下标范围是 `0` 到 `4`。访问 `values[5]` 或 `values[-1]` 都是越界访问，属于未定义行为。越界可能暂时看似正常，也可能修改其他数据或导致崩溃，不能依赖运行结果。

### 26. 数组名和指针是同一种东西吗？

不是。在很多表达式中，数组名会转换为指向首元素的指针，但数组本身仍然是数组：

```cpp
int values[3]{10, 20, 30};
int* pointer = values;
```

`sizeof(values)` 得到整个数组大小，而 `sizeof(pointer)` 得到指针大小。数组作为函数参数时通常会调整为指针，因此函数内不能再通过 `sizeof` 得到原数组长度，需要额外传长度或使用 `std::span`。

### 27. `int* p`、`&x` 和 `*p` 分别表示什么？

```cpp
int x{10};
int* p{&x};
```

`x` 是对象本身，`&x` 是对象地址，`p` 保存这个地址，`*p` 是解引用并访问 `p` 指向的对象。

`int* p;` 未初始化，可能保存任意地址，直接解引用是错误的。应初始化为有效地址或 `nullptr`。

### 28. `nullptr` 和 `NULL` 有什么区别？

现代 C++ 推荐：

```cpp
int* pointer{nullptr};
```

`nullptr` 是专门的空指针字面量，类型更明确。传统的 `NULL` 通常是整数 `0` 或宏，可能在重载调用中造成歧义。新代码应优先使用 `nullptr`。

### 29. `const int*` 和 `int* const` 有什么区别？

`const int* p1` 表示指向常量整数的指针：不能通过 `p1` 修改对象，但 `p1` 可以重新指向其他对象。

`int* const p2 = &value` 表示常量指针：`p2` 不能重新指向其他对象，但可以通过 `p2` 修改对象。

`const int* const p3 = &value` 表示指针和指向的对象都不能通过该路径修改。判断时可以从变量名向右、再向左读声明。

### 30. 为什么现代 C++ 更推荐 `std::vector`、`std::array` 和 `std::span`？

内置数组和裸指针缺少边界和所有权信息，容易出现越界、长度丢失、内存泄漏、悬空指针以及 `new`/`delete` 不匹配。

- `std::array<T, N>`：固定大小，具有值语义；
- `std::vector<T>`：动态大小，自动管理内存，元素通常连续存储；
- `std::span<T>`：非拥有的连续数据视图，不负责释放底层内存。

`std::span` 不会延长底层数据的生命周期，因此不能返回指向已经销毁的局部数组的 `span`。

## 六、面试现场代码题

### 31. 数组参数中的 `sizeof` 有什么问题？

```cpp
void print(int values[]) {
    std::cout << sizeof(values) << '\n';
}
```

数组参数会调整为指针，等价于接收 `int*`。因此 `sizeof(values)` 得到的是指针大小，不是数组大小。可以改为 `void print(const int* values, std::size_t count);`，或者使用 `std::span<const int>`。

### 32. 下面代码输出什么？

```cpp
int value{0};

if (value = 5) {
    std::cout << "true";
} else {
    std::cout << "false";
}
```

输出 `true`。`value = 5` 是赋值表达式，结果为 `5`，转换为布尔值后为真。若本意是比较，应写成 `value == 5`。

### 33. 下面代码有什么风险？

```cpp
std::vector<int> values{1, 2, 3};

for (int i = values.size() - 1; i >= 0; --i) {
    std::cout << values[i];
}
```

`values.size()` 的类型是无符号的 `std::size_t`。当数组为空时，`values.size() - 1` 会发生无符号下溢，得到很大的数。可以使用反向迭代器：

```cpp
for (auto it = values.rbegin(); it != values.rend(); ++it) {
    std::cout << *it;
}
```

### 34. 如何判断一个错误属于编译错误还是链接错误？

如果调用前有函数声明但没有定义，源文件通常可以编译，最终链接失败：

```cpp
int add(int, int);

int main() {
    return add(1, 2);
}
```

如果连声明都没有，编译器会报告函数未声明。如果语法本身不合法，例如 `int value = ;`，则属于编译错误。

## 七、第一章掌握标准

面试时不能只停留在“看过笔记”。至少应该能够：

- 解释预处理、编译、汇编、链接和运行的区别；
- 分辨编译错误、链接错误、运行时错误和逻辑错误；
- 写出命令行参数程序，并检查 `argc`；
- 解释整数除法、窄化转换和有符号/无符号混合比较；
- 根据语义选择值、`T&`、`const T&` 或 `T*`；
- 解释数组退化、指针解引用、空指针和悬空引用；
- 说明为什么现代 C++ 优先使用 `std::vector`、`std::array`、`std::string` 和 `std::span`；
- 使用编译器警告定位至少一个故意写出的错误。
