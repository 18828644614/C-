# 类型、变量与常量

## 学习目标

- [ ] 理解“类型、对象、变量”三者的关系，并能选择合适的基本类型。
- [ ] 区分声明、定义、初始化和赋值，掌握安全、清晰的初始化方式。
- [ ] 理解作用域与生命周期，避免使用未初始化变量和已经失效的对象。
- [ ] 正确使用 `const`、`constexpr` 和枚举常量表达不可修改的值。
- [ ] 看懂隐式转换、显式转换、整数除法、溢出和有符号/无符号混用等常见问题。

## 要点

## 1. 先建立整体认识：类型、对象和变量

### 1.1 类型决定“值如何解释”和“可以做什么操作”

计算机内存本质上只保存一串二进制位。同样的二进制位，按整数解释、按浮点数解释或按字符解释，得到的结果可能完全不同。**类型**就是一组规则，它告诉编译器：

- 一个值占用多大的存储空间（具体大小由实现和平台决定）；
- 这段存储中的位应该如何解释；
- 哪些运算是合法的，例如整数可以做取模，`bool` 适合表示真假；
- 进行表达式计算和类型转换时应该遵循什么规则。

例如，`65` 是一个整数，而字符字面量 `'A'` 是一个字符。它们在很多实现中使用相同的编码值，但类型不同，表达的含义也不同。

~~~cpp
int number = 65;
char letter = 'A';

// number + 1 是整数运算；letter + 1 也会先提升为整数再运算。
~~~

不要把“占用相同字节数”理解成“类型相同”。类型信息会影响编译器的检查、重载选择、运算结果和可读性。

### 1.2 对象和变量是什么

**对象**是运行期间占用一段存储空间、具有类型和生命周期的实体。一个对象可以没有名字（例如临时对象），也可以通过名字访问。

**变量**通常是一个有名字的对象。下面的代码声明了一个名为 `age`、类型为 `int` 的变量，并在创建时给它初始值 18：

~~~cpp
int age = 18;
~~~

可以把它暂时想象成一个贴有标签的储物格：`int` 规定储物格如何解释内容，`age` 是标签，`18` 是创建时放入的初始内容。这个比喻有助于入门，但真实的 C++ 对象还涉及地址、对齐和生命周期等更精确的规则。

### 1.3 常见基本类型

下表列出初学阶段最常用的类型。除 `bool`、`char` 等少数类型外，标准通常只规定范围关系和最小宽度，不保证每个平台的字节数完全相同。

| 类型 | 用途 | 示例 | 注意事项 |
| --- | --- | --- | --- |
| `bool` | 真或假 | `true`、`false` | 输出时默认显示 `1`、`0`，可用 `std::boolalpha` 显示文字 |
| `char` | 一个窄字符或小整数 | `'A'`、`'?'` | 是否有符号由实现决定；不要用它代替完整的 Unicode 文本 |
| `wchar_t`、`char8_t`、`char16_t`、`char32_t` | 特定字符编码场景 | `U'中'` | 编码和库支持较复杂，初学文本优先使用 `std::string`/UTF-8 |
| `short`、`int`、`long`、`long long` | 整数 | `42`、`-7` | `long` 在 Windows 64 位通常仍为 32 位，不要猜测其大小 |
| `unsigned` 整数 | 不需要负数的非负整数 | `0u`、`10u` | 参与比较时可能造成意外的无符号转换 |
| `float`、`double`、`long double` | 带小数的近似数 | `3.14`、`2.0` | 浮点数有舍入误差，不能随意用 `==` 比较 |
| `std::string` | 可变长度的文本 | `"hello"` | 需要 `#include <string>`；保存的是字符序列，不是单个 `char` |
| `void` | 表示“没有值” | `void print()` | 不能声明 `void` 类型的普通变量 |

整数类型的实际宽度可用 `sizeof` 查询，不能仅凭经验假定：

~~~cpp
#include <iostream>

int main() {
    std::cout << "int 占用 " << sizeof(int) << " 个字节\n";
    std::cout << "double 占用 " << sizeof(double) << " 个字节\n";
}
~~~

如果需要明确的位宽，可以使用 `<cstdint>` 中的 `std::int32_t`、`std::uint64_t` 等类型；但相应类型只有在平台提供时才会定义。

### 1.4 有符号与无符号

普通整数类型默认是有符号的，可以表示负数、零和正数；在类型前加 `unsigned` 表示只表示非负数。例如：

~~~cpp
int temperature{-5};
unsigned int count{5};
~~~

无符号类型并不是“更安全的整数”。无符号减法在结果为负时会按模运算回绕，和直觉可能不同：

~~~cpp
unsigned int count{0};
// --count; // 结果会回绕到一个很大的无符号值，不会变成 -1
~~~

表示数量、下标时经常会遇到 `std::size_t`（无符号类型）。比较它和 `int` 时要留意：负数转换为无符号数后可能变成很大的正数。除非确实需要非负范围或与标准库接口匹配，否则初学时优先使用含义明确的 `int`。

## 2. 变量：声明、定义、初始化与赋值

### 2.1 声明和定义

**声明（declaration）**告诉编译器某个名字和类型；**定义（definition）**还会为对象提供存储（或给出实体的完整内容）。在函数内部写普通变量时，声明通常同时也是定义：

~~~cpp
int score; // 声明并定义一个 int 对象，但没有提供初始值
~~~

跨源文件使用全局对象时，才常见“只声明、后定义”的形式：

~~~cpp
// header.h
extern int shared_value; // 只声明，不创建对象

// one.cpp
int shared_value = 10;   // 定义一次
~~~

初学阶段可以先记住：同一个实体通常应当只有一个定义；头文件中的普通全局定义容易造成重复定义，后续学习源文件、编译与链接时会进一步展开。

### 2.2 初始化不是赋值

**初始化**发生在对象创建时；**赋值**发生在对象已经存在之后：

~~~cpp
int score = 80; // 初始化：创建 score 时给初值
score = 90;     // 赋值：把新值写入已经存在的 score
~~~

推荐优先使用花括号初始化。它形式统一，并且会阻止很多可能丢失数据的“窄化转换”：

~~~cpp
int count{10};
double price{19.9};

// int truncated{3.14}; // 错误：列表初始化禁止 double 到 int 的窄化转换
int truncated = 3.14;   // 通常可以编译，但小数部分会被截去，容易隐藏错误
~~~

### 2.3 默认初始化、值初始化和未初始化

不同写法的初始状态不同：

~~~cpp
int a;      // 局部变量：未初始化，值不确定
int b{};    // 值初始化，int 得到 0
int c = 0;  // 明确初始化为 0

int numbers[3]{}; // 数组元素全部值初始化为 0
~~~

读取未初始化的局部变量是严重错误。对于某些类型，这会产生**未定义行为**，程序可能输出看似合理的随机值，也可能在优化后表现完全不同。养成“声明时就初始化”的习惯：

~~~cpp
int input{};
std::string message{};
~~~

静态存储期对象会自动进行零初始化，但不应因此放松对普通局部变量的初始化要求。

### 2.4 作用域和生命周期

**作用域**回答“名字在哪里可见”；**生命周期**回答“对象从何时存在到何时销毁”。二者相关但不是同一个概念：

~~~cpp
#include <iostream>

int global_value{1}; // 命名空间作用域，程序运行期间一直存在

int main() {
    int value{10};
    {
        int value{20}; // 隐藏外层同名变量
        std::cout << value << '\n'; // 20
    }
    std::cout << value << '\n';     // 10
}
~~~

把变量放在“实际需要的最小作用域”中，能减少意外修改。尽量避免为了方便访问而大量使用全局可变变量；全局状态会让函数之间的依赖更难追踪。

## 3. 常量：表达“不应被修改”的值

### 3.1 `const` 变量

`const` 表示对象初始化后不能通过这个名字修改。常量必须在创建时初始化：

~~~cpp
const double pi{3.141592653589793};
const int max_retries{3};

// pi = 3.0;       // 错误：不能给 const 对象赋值
// const int n;     // 错误：const 对象没有初始值
~~~

`const` 是编译器检查的一部分：如果代码试图修改常量，编译器会报错。对于运行期间才知道、但之后不应再改变的值，`const` 非常合适。

### 3.2 `constexpr`：要求编译期可计算

`constexpr` 表示变量或函数可以在编译期求值；用于变量时，初始化表达式必须是常量表达式：

~~~cpp
constexpr int seconds_per_minute{60};
constexpr int minutes_per_hour{60};
constexpr int seconds_per_hour{seconds_per_minute * minutes_per_hour};
~~~

`constexpr` 变量同时具有 `const` 的不可修改性质。普通 `const` 则只保证“初始化后不能修改”，初始值不一定能在编译期得到：

~~~cpp
int read_number();
const int runtime_value{read_number()}; // 运行时初始化，但之后不可修改
// constexpr int compile_value{read_number()}; // 错误：不是常量表达式
~~~

C++20 的 `consteval` 更严格：被标记的函数每次调用都必须在编译期求值，初学时了解概念即可。

### 3.3 枚举常量和命名方式

用有意义的名字代替散落在代码中的“魔法数字”，程序更容易阅读和维护：

~~~cpp
enum class LogLevel { info, warning, error };
LogLevel level{LogLevel::warning};
~~~

`enum class` 是作用域枚举，枚举项需要写成 `LogLevel::warning`，不容易与其他名字冲突，也不会自动当成普通整数参与大多数运算。若确实要得到底层整数，可以显式转换：

~~~cpp
int code = static_cast<int>(level);
~~~

宏常量（如 `#define PI 3.14`）不受类型检查和作用域规则约束。新代码通常优先使用 `constexpr`、`const` 或 `enum class`。

## 4. 类型转换：值改变之前先想清楚规则

### 4.1 隐式转换

当表达式中出现不同类型时，C++ 可能自动转换类型。例如整数和浮点数相加时，整数通常会转换为浮点数：

~~~cpp
int count{3};
double average{count / 2.0}; // count 隐式转换为 double，结果为 1.5
~~~

隐式转换很方便，但也可能悄悄丢失信息。赋值给更窄的类型、把负数转成无符号数、不同宽度整数混合比较，都应特别谨慎。

### 4.2 显式转换：优先使用 `static_cast`

当转换是有意的，用 `static_cast<目标类型>(表达式)` 把意图写出来：

~~~cpp
int total{5};
int people{2};

double wrong = total / people; // 先做整数除法，结果是 2，再转成 2.0
double right = static_cast<double>(total) / people; // 先转成 double，结果为 2.5
~~~

`static_cast` 能让代码更清楚，也能让编译器检查某些不合适的转换。C 风格强制转换（如 `(double)total`）语义不够明确，现代 C++ 通常不推荐。

### 4.3 窄化转换、溢出和浮点误差

- **窄化转换**：目标类型能表示的范围或精度更小，例如 `double` 转 `int` 会丢掉小数；花括号初始化会拒绝很多此类转换。
- **整数溢出**：有符号整数超出可表示范围会产生未定义行为；无符号整数按模回绕。应检查范围，必要时使用更宽类型或安全的算术逻辑。
- **浮点误差**：`0.1 + 0.2` 可能不精确等于 `0.3`。比较浮点数时通常要比较误差是否小于容许值，而不是直接使用 `==`。

~~~cpp
#include <cmath>

double a{0.1 + 0.2};
double b{0.3};
if (std::abs(a - b) < 1e-12) {
    // 在给定误差范围内认为相等
}
~~~

### 4.4 字符、布尔值和整数之间的转换

字符和布尔值在需要时可以参与整数运算，但要保持意图明确：

~~~cpp
char ch{'A'};
int code = static_cast<unsigned char>(ch); // 得到字符编码对应的非负整数
bool ok{true};
int flag = static_cast<int>(ok); // 1
~~~

不要依赖具体字符编码的数值来判断语言文字；ASCII 对英文字母和数字的关系有保证，其他字符集应交给合适的文本库处理。

## 5. 指针声明中的 `const`（先掌握读法）

指针和 `const` 的组合容易混淆。先从右向左读：

~~~cpp
int value{10};
int other{20};

const int* p1{&value}; // p1 指向 const int：不能通过 p1 修改 value，但 p1 可以改指向
int* const p2{&value}; // p2 是 const 指针：p2 不能改指向，但可以通过 p2 修改 value
const int* const p3{&value}; // 指向 const int 的 const 指针：两者都不能改

p1 = &other;   // 合法
// *p1 = 11;    // 错误：不能通过 p1 修改
// p2 = &other; // 错误：p2 本身不能改指向
*p2 = 11;      // 合法
~~~

这里的 `const` 只限制相应的修改路径，并不会把对象本身“变成另一个类型”。如果原对象不是 `const`，仍可通过其他合法名字修改它；如果原对象本来就是 `const`，就不能用强制转换绕过限制，否则可能产生未定义行为。

## 6. 常见错误与排查思路

| 错误写法或现象 | 原因 | 修改方向 |
| --- | --- | --- |
| `int value; std::cout << value;` | 局部变量未初始化，读取其值可能是未定义行为 | 写成 `int value{};`，或在读取前明确赋值 |
| `const int limit;` | `const` 对象必须在创建时初始化 | 写成 `const int limit{10};` |
| `int n = 3.14;` | 隐式窄化，3.14 被截成 3 | 优先使用 `int n{3.14};` 让编译器拒绝，或明确使用 `static_cast<int>` |
| `double average = total / count;` | 两个操作数都是整数，先发生整数除法 | 写成 `static_cast<double>(total) / count` |
| `if (x < vector.size())` 中 `x` 为负数 | `x` 可能先转换成无符号的 `size_t`，比较结果反直觉 | 先检查 `x >= 0`，或统一使用合适的类型 |
| `unsigned n = 0; --n;` 后得到很大数 | 无符号运算按模回绕 | 设计逻辑避免减到负数，或使用有符号类型 |
| `const` 变量仍被某处修改 | 误解了对象本身、指针和指向对象的常量性 | 区分 `const int*` 与 `int* const` |
| 用 `#define PI 3.14` 定义常量 | 宏没有类型、作用域和调试信息 | 使用 `constexpr double pi{3.14};` |
| 直接用 `a == b` 比较两个 `double` | 浮点数可能存在舍入误差 | 比较 `std::abs(a - b)` 是否小于合理误差 |
| 以为 Windows 64 位的 `long` 一定是 64 位 | Windows 使用 LLP64，`long` 通常仍为 32 位 | 用 `sizeof` 检查，或使用 `<cstdint>` 定宽类型 |

排查类型问题时，可以按顺序检查：变量声明类型；表达式各操作数类型；是否发生隐式转换；转换是否丢失范围或精度；作用域和生命周期是否仍然有效。MSVC 建议使用 `/W4`，MinGW-w64 建议使用 `-Wall -Wextra -pedantic`。

## 示例与实践

### 1. 可运行的综合示例：类型、初始化、常量与转换

下面的程序不依赖平台特有 API，可在 Windows 的 MSVC 或 MinGW-w64 中运行。它演示基本类型、列表初始化、`const`、`constexpr`、`enum class`、作用域和整数除法。将代码保存为 `types_variables_constants.cpp`，文件建议使用 UTF-8 编码。

~~~cpp
#include <cstdint>
#include <iomanip>
#include <iostream>
#include <string>

constexpr int square(int value) {
    return value * value;
}

enum class TrafficLight { red, yellow, green };

int main() {
    int age{18};
    double height{1.75};
    char grade{'A'};
    bool is_student{true};
    std::string name{"小明"};
    std::int32_t points{95};

    const double tax_rate{0.13};
    constexpr int days_per_week{7};
    constexpr int age_squared{square(18)};

    std::cout << std::boolalpha; // 让 bool 输出 true/false，而不是 1/0
    std::cout << "姓名：" << name << '\n'
              << "年龄：" << age << '\n'
              << "身高：" << height << " 米\n"
              << "等级：" << grade << '\n'
              << "是否学生：" << is_student << '\n'
              << "积分：" << points << '\n';

    std::cout << "int 大小：" << sizeof(int) << " 字节\n"
              << "double 大小：" << sizeof(double) << " 字节\n";

    int total{5};
    int people{2};
    double wrong_average = total / people; // 先整数除法，结果为 2.0
    double right_average = static_cast<double>(total) / people; // 结果为 2.5
    std::cout << "错误的平均值：" << wrong_average << '\n'
              << "正确的平均值：" << right_average << '\n';

    TrafficLight light{TrafficLight::green};
    if (light == TrafficLight::green) {
        std::cout << "现在可以通行。\n";
    }

    {
        int age{30}; // 只在这个代码块内可见，隐藏外层的 age
        std::cout << "内层年龄：" << age << '\n';
    }
    std::cout << "外层年龄：" << age << '\n';

    std::cout << "税率：" << std::fixed << std::setprecision(2)
              << tax_rate * 100 << "%\n"
              << "一周天数：" << days_per_week << '\n'
              << "18 的平方：" << age_squared << '\n';
}
~~~

在 Visual Studio Developer PowerShell 中编译：

~~~powershell
cl /std:c++20 /W4 /EHsc /utf-8 types_variables_constants.cpp /Fe:types_variables_constants.exe
.\types_variables_constants.exe
~~~

在已配置 MinGW-w64 的 PowerShell 中编译：

~~~powershell
g++ -std=c++20 -Wall -Wextra -pedantic types_variables_constants.cpp -o types_variables_constants.exe
.\types_variables_constants.exe
~~~

如果中文显示为乱码，可确认源文件保存为 UTF-8，并在较旧的 Windows 终端中尝试先执行 `chcp 65001`。编译器警告应尽量修复，而不是简单关闭。

### 2. 练习

1. 声明表示商品名称、单价、库存数量和是否上架的变量，分别选择合适的类型，并在声明时初始化。
2. 写一个程序读取两个整数，输出整数商和带小数的精确商；解释为什么两种结果不同。
3. 把一个普通 `const` 变量改成 `constexpr`，观察它的初始值必须满足什么条件。
4. 使用 `enum class` 表示星期或交通灯状态，并用 `if` 或 `switch` 根据枚举值输出文字。
5. 编写一个程序计算圆的面积：把圆周率定义为 `constexpr`，半径从用户输入获得，并检查半径是否为负数。
6. 找出一段使用“魔法数字”和 C 风格强制转换的旧代码，分别改成命名常量和 `static_cast`，比较可读性。

完成后，尝试用自己的话回答：

- 类型为什么不仅决定变量占用多少空间，还会影响运算和编译器检查？

- `const` 与 `constexpr` 的共同点和区别是什么？
- `5 / 2` 为什么是 `2`，怎样写才能得到 `2.5`？
- 有符号整数和无符号整数混合比较时，为什么可能得到意外结果？
- `const int*` 和 `int* const` 分别限制了什么？
