# 基本语法与控制流

## 学习目标

- [ ] 看懂 C++ 程序中的注释、标识符、表达式、语句和代码块。
- [ ] 正确使用 `if`、`else`、`switch` 组织条件分支，并理解比较、逻辑运算和短路求值。
- [ ] 使用 `for`、`while`、`do...while` 和范围 `for` 编写重复执行的程序。
- [ ] 理解 `break`、`continue`、`return` 对执行流程的影响。
- [ ] 能根据问题选择合适的控制结构，并识别死循环、少写分号、整数除法等常见错误。

## 要点

## 1. 先认识 C++ 代码的基本组成

### 1.1 注释：写给人看的说明

编译器会忽略注释，不会把它当成要执行的程序。注释的作用是解释“为什么这样写”或补充必要背景，而不是把每一行代码翻译成中文。

~~~cpp
// 这是单行注释，从 // 开始到本行末尾结束
int age = 18; // 也可以写在语句后面

/*
   这是多行注释，可以跨越多行。
   注意：多行注释不能嵌套。
*/
~~~

过时或与代码不符的注释比没有注释更容易误导。修改代码时也要同步检查注释。调试时可以暂时注释掉一小段代码，但不建议长期保留大量“被注释掉的旧代码”；版本控制系统更适合保存历史版本。

### 1.2 标识符、关键字和大小写

**标识符**是程序员为变量、函数、类型等声明的名字，例如 `total_count`。常见规则如下：

- 只能包含字母、数字和下划线，不能含空格或连字符；
- 不能以数字开头；
- 不能使用 C++ 关键字，例如 `if`、`for`、`class`、`return`；
- C++ 区分大小写，`score`、`Score` 和 `SCORE` 是三个不同的名字。

~~~cpp
int item_count = 3; // 合法，使用下划线分隔单词
int item2 = 4;      // 合法，数字不能放在开头但可以放在后面
// int 2items = 4;  // 错误：标识符不能以数字开头
// int class = 1;   // 错误：class 是关键字
~~~

建议使用能表达含义的名字，如 `retry_count`、`is_valid`，而不是 `a`、`b`、`x1`。命名风格可以因项目而异，只要在同一项目中保持一致即可。

### 1.3 字面量、表达式和语句

**字面量**是直接写在源代码中的值，如 `42`、`3.14`、`'A'` 和 `"hello"`。由运算符、变量和字面量组合起来、能够计算出一个值的部分称为**表达式**：

~~~cpp
int width = 3;
int area = width * 4; // width * 4 是表达式，结果为 12
~~~

以分号 `;` 结束、表示一个完整动作的通常是**语句**。声明变量、赋值、调用函数都可以构成语句：

~~~cpp
int number = 10;       // 声明和初始化语句
number = number + 1;   // 赋值语句
std::cout << number;   // 输出语句
~~~

花括号 `{}` 包围的一组语句称为**复合语句**或**代码块**。控制结构通常把代码块作为自己的执行主体：

~~~cpp
if (number > 0) {
    std::cout << "正数\n";
    std::cout << "仍在 if 代码块内\n";
}
~~~

即使代码块中只有一条语句，也建议写花括号。这样以后添加第二条语句时不容易产生缩进看起来属于 `if`、实际却不受条件控制的错误。

### 1.4 运算符和优先级：必要时主动加括号

常见运算符可以按用途理解：

- 算术：`+`、`-`、`*`、`/`、`%`；
- 比较：`<`、`<=`、`>`、`>=`、`==`、`!=`，结果是 `bool`；
- 逻辑：`&&`（并且）、`||`（或者）、`!`（取反）；
- 赋值：`=`、`+=`、`-=`、`*=`、`/=`；
- 自增/自减：`++`、`--`。

乘除通常先于加减，比较通常晚于算术，逻辑 `&&` 又通常先于 `||`。不过不要依赖记忆复杂优先级，遇到不确定的表达式就加括号：

~~~cpp
bool eligible = (age >= 18) && has_id;
int result = (a + b) * c;
~~~

`=` 是赋值，`==` 才是相等比较；这是初学者最常见的混淆之一。`a / b` 如果 `a`、`b` 都是整数，结果也是整数，小数部分会被截去；需要小数结果时可让至少一个操作数为浮点数，例如 `a / 2.0`。

`++i` 和 `i++` 都会让 `i` 增加 1，但表达式的值不同：前者先增加再取值，后者先取旧值再增加。初学时建议把自增单独写成一条语句，避免把多个副作用塞进一个复杂表达式。

## 2. 条件分支：让程序根据情况做不同的事

### 2.1 `if`：最基本的条件语句

`if (条件) { ... }` 先计算括号中的条件。条件结果为 `true` 时执行代码块，为 `false` 时跳过。整数、指针等也可以被转换为布尔值，但初学时最好直接写出比较表达式：

~~~cpp
#include <iostream>

int main() {
    int temperature = 28;

    if (temperature >= 30) {
        std::cout << "天气很热\n";
    }

    if (temperature < 30) {
        std::cout << "还没有达到 30 度\n";
    }
}
~~~

如果条件代码块只有一条语句，省略花括号在语法上可能合法，但容易导致“悬空 `else`”或错误缩进。统一保留花括号是更稳妥的习惯。

### 2.2 `if...else` 和 `else if`

`else` 与前面最近的、尚未匹配 `else` 的 `if` 配对。使用花括号可以让配对关系清楚：

~~~cpp
if (score >= 60) {
    std::cout << "及格\n";
} else {
    std::cout << "需要继续练习\n";
}
~~~

多个互斥区间可以用 `else if` 串起来。条件会从上到下依次检查，命中第一个为真的分支后，后面的条件不再检查：

~~~cpp
if (score >= 90) {
    std::cout << "优秀\n";
} else if (score >= 80) {
    std::cout << "良好\n";
} else if (score >= 60) {
    std::cout << "及格\n";
} else {
    std::cout << "不及格\n";
}
~~~

条件顺序很重要。例如先判断 `score >= 60`，那么 90 分也会在第一个分支结束，后面的“优秀”永远到不了。把更严格的条件放在前面，或先检查输入是否在合法范围内。

### 2.3 逻辑运算与短路求值

`&&` 要求两边都为真，`||` 只要一边为真，`!` 把真假反转。C++ 采用**短路求值**：

- `A && B` 中，如果 `A` 已经为假，`B` 不会计算；
- `A || B` 中，如果 `A` 已经为真，`B` 不会计算。

这不仅能提高效率，还能安全地安排检查顺序：

~~~cpp
if (pointer != nullptr && *pointer > 0) {
    // 只有 pointer 非空时，才会读取 *pointer
}
~~~

不要把 `&`、`|` 与 `&&`、`||` 混用。前一对是按位运算符，后一对是逻辑运算符。比较多个条件时，主动加括号能减少误解。

### 2.4 条件运算符 `?:`

当两个分支都只是产生一个值时，可以使用条件运算符：

~~~cpp
int number = 7;
const char* parity = (number % 2 == 0) ? "偶数" : "奇数";
~~~

它的格式是 `条件 ? 条件为真时的值 : 条件为假时的值`。嵌套多个 `?:` 会迅速降低可读性；如果分支包含多条语句，应该使用普通 `if...else`。

### 2.5 `switch`：根据一个离散值选择分支

当要比较同一个整数、字符或枚举值的多个固定选项时，`switch` 往往比很长的 `else if` 更清晰：

~~~cpp
char command = 's';

switch (command) {
case 's':
    std::cout << "保存\n";
    break; // 结束 switch，防止继续执行下一个 case
case 'q':
    std::cout << "退出\n";
    break;
default:
    std::cout << "未知命令\n";
    break;
}
~~~

`case` 标签后通常需要 `break`。如果省略，程序会继续执行后面的 `case`，这叫**贯穿（fallthrough）**。有意贯穿时应写注释，避免读者以为是遗漏。

`switch` 不能直接用 `std::string` 做条件；字符串应使用 `if` 比较，或先转换为枚举/字符。每个 `case` 中声明变量时，若不同 `case` 可能跳过该声明，建议用花括号包住各自代码块：

~~~cpp
switch (option) {
case 1: {
    int value = 10;
    std::cout << value << '\n';
    break;
}
case 2:
    std::cout << "另一个选项\n";
    break;
default:
    break;
}
~~~

## 3. 循环：重复执行一段代码

循环通常包含三件事：**初始状态**、**继续条件**和**状态更新**。如果更新步骤不会让条件最终变为假，就可能出现死循环。

### 3.1 `while`：先判断，再执行

`while` 每次执行循环体前先检查条件。如果一开始条件就是假，循环一次也不会执行：

~~~cpp
int count = 3;
while (count > 0) {
    std::cout << count << '\n';
    --count; // 更新状态，否则 count 永远大于 0 会造成死循环
}
std::cout << "发射！\n";
~~~

`while` 适合“事先不知道要循环多少次”的场景，例如不断读取输入，直到用户输入特定结束标记。

### 3.2 `do...while`：至少执行一次

`do...while` 先执行循环体，再检查条件，因此无论条件初始真假，循环体都会执行一次。结尾的分号是语法的一部分：

~~~cpp
int choice;
do {
    std::cout << "请输入 1（继续）或 0（退出）：";
    std::cin >> choice;
} while (choice != 0 && choice != 1);
~~~

它适合菜单、输入提示等“必须先显示或尝试一次”的场景。若把最后的分号漏掉，编译器会报语法错误。

### 3.3 `for`：把计数循环写在一起

经典 `for` 的格式是 `for (初始化; 条件; 更新) { 循环体 }`：

~~~cpp
for (int i = 1; i <= 5; ++i) {
    std::cout << i << ' ';
}
std::cout << '\n';
~~~

执行顺序是：初始化一次 → 判断条件 → 执行循环体 → 执行更新 → 再次判断条件。`i` 在 `for` 的初始化部分声明时，只在该 `for` 语句及其循环体内可见：

~~~cpp
for (int i = 0; i < 3; ++i) {
    // i 可见
}
// i 在这里不可见
~~~

三个部分都可以省略，但分号不能少。例如 `for (;;) {}` 是一个没有终止条件的无限循环，必须依靠 `break`、`return` 或其他外部机制结束。

### 3.4 范围 `for`：遍历容器中的每个元素

C++11 起可以使用范围 `for`，不需要手动管理下标或迭代器：

~~~cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> scores{80, 92, 75};

    for (int score : scores) {
        std::cout << score << '\n'; // score 是每个元素的副本
    }

    for (int& score : scores) {
        ++score; // 引用元素本身，修改会写回 vector
    }

    for (const int& score : scores) {
        std::cout << score << ' '; // 只读，不复制较大对象
    }
}
~~~

只读遍历时可写 `const auto&`；需要修改元素时写 `auto&`。如果只写 `auto score`，修改的是副本，不会影响容器。范围 `for` 适合“逐个处理全部元素”，需要下标或提前停止时可以使用普通 `for`，或配合 `break`。

## 4. 改变控制流：`break`、`continue` 和 `return`

### 4.1 `break`：结束最近的一层循环或 `switch`

`break` 只结束它所在的最近一层 `for`、`while`、`do...while` 或 `switch`，不会自动结束外层循环：

~~~cpp
for (int i = 1; i <= 10; ++i) {
    if (i == 4) {
        break;
    }
    std::cout << i << ' '; // 输出 1 2 3
}
~~~

### 4.2 `continue`：跳过本轮剩余代码

`continue` 会跳过本轮循环体剩余部分，直接开始下一轮。对于经典 `for`，它会先执行更新表达式，再重新判断条件；对于 `while`，会直接回到条件判断处：

~~~cpp
for (int i = 1; i <= 5; ++i) {
    if (i % 2 == 0) {
        continue; // 跳过偶数
    }
    std::cout << i << ' '; // 输出 1 3 5
}
~~~

在 `while` 中使用 `continue` 时，务必保证更新状态的代码仍有机会执行，否则可能把循环变成死循环：

~~~cpp
int i = 0;
while (i < 5) {
    ++i; // 放在 continue 之前，确保每轮都会更新
    if (i == 3) {
        continue;
    }
    std::cout << i << '\n';
}
~~~

### 4.3 `return`：离开当前函数

`return` 不仅可以交出返回值，还会立即结束当前函数。它可以从循环嵌套中直接返回到调用者：

~~~cpp
#include <vector>

bool contains_zero(const std::vector<int>& values) {
    for (int value : values) {
        if (value == 0) {
            return true; // 找到后立即结束整个函数
        }
    }
    return false;
}
~~~

`break`、`continue` 和 `return` 的范围不同：`break` 离开最近一层循环或 `switch`，`continue` 只结束本轮循环，`return` 离开整个函数。

## 5. 代码块、作用域与变量生命周期

每一对花括号通常创建一个块作用域。在内层作用域声明的名字，只能从声明处使用到该代码块结束；内层可以使用外层已经可见的变量，外层不能使用内层变量：

~~~cpp
int main() {
    int total = 10;
    {
        int bonus = 2;
        total += bonus; // 可以访问外层 total
    }
    // std::cout << bonus; // 错误：bonus 已超出作用域
}
~~~

变量离开作用域时，普通局部对象的生命周期通常也会结束。不要为了“让变量一直可见”而把所有变量都声明成全局变量；尽量把变量放在实际需要的最小作用域中，这样更不容易被意外修改。

如果内层作用域声明了同名变量，它会**隐藏**外层变量：

~~~cpp
#include <iostream>

int main() {
    int value = 10;
    {
        int value = 20; // 这里只能直接访问内层 value
        std::cout << value << '\n'; // 20
    }
    std::cout << value << '\n'; // 10
}
~~~

名称隐藏不是赋值，内层 `value` 与外层 `value` 是两个对象。相邻嵌套块尽量不要重复命名，以免阅读和调试困难。

## 6. 输入、循环与错误处理的基本模式

从 `std::cin` 读取输入时，用户可能输入字母、超出范围的数字或直接结束输入。读取失败后，流会进入失败状态，后续读取通常不会成功。简单程序可以这样恢复：

~~~cpp
#include <iostream>

int main() {
    int age{};
    while (true) {
        std::cout << "请输入 0 到 150 之间的年龄：";
        if (std::cin >> age && age >= 0 && age <= 150) {
            break; // 输入成功且范围合法
        }

        std::cout << "输入无效，请重试。\n";
        std::cin.clear(); // 清除 fail 状态
        std::cin.ignore(10000, '\n'); // 丢弃本行剩余错误字符
    }

    std::cout << "记录的年龄是 " << age << '\n';
}
~~~

`std::cin.clear()` 只清除状态，不会删除输入缓冲区中的错误字符；通常还要配合 `ignore`。在更复杂的程序中，可以读取整行字符串后自行解析，以便提供更精确的错误提示。

## 7. 常见错误与排查思路

| 错误写法或现象 | 原因 | 修改方向 |
| --- | --- | --- |
| `if (x = 5)` | 把赋值 `=` 写成了比较 `==` | 改为 `if (x == 5)`；开启编译器警告 |
| `if (x > 0); { ... }` | `if` 后多了分号，条件控制了一个空语句 | 删除多余分号，并保留花括号 |
| `else` 报错或与预期分支不符 | `else` 只和最近的未匹配 `if` 配对，或缩进误导了阅读 | 给每个分支写花括号，重新检查配对关系 |
| `switch` 执行了多个 `case` | 忘记写 `break`，发生贯穿 | 在需要结束的 `case` 末尾写 `break` |
| 循环永远不结束 | 循环条件始终为真，或忘记更新计数变量 | 列出每轮状态，确认最终能使条件为假 |
| `while` 中 `continue` 后计数不变 | 跳过了更新语句 | 把更新放到 `continue` 之前，或改写循环结构 |
| `for (int i = 0; i <= n; ++i)` 访问越界 | 下标通常是 `0` 到 `n - 1`，`i == n` 已越界 | 使用 `i < n`，并检查容器是否为空 |
| `5 / 2` 得到 `2` | 两个操作数都是整数，发生整数除法 | 使用 `5.0 / 2` 或显式转换为浮点类型 |
| 把 `&` 当成“并且” | `&` 是按位与，逻辑与应写 `&&` | 区分按位运算和逻辑运算 |
| 只在循环内声明的变量在循环后无法使用 | 变量的块作用域已结束 | 在共同的外层作用域声明，或在循环中完成处理 |
| 条件中调用有副作用的函数导致难以理解 | 短路求值可能使函数根本不被调用 | 将副作用单独写成语句，再判断结果 |

遇到控制流问题时，可以先在关键位置输出变量值，或使用 Visual Studio/VS Code 的断点调试。编译时建议开启警告：MSVC 使用 `/W4`，MinGW-w64 使用 `-Wall -Wextra -pedantic`；警告经常能提前发现分号、未初始化变量和可能遗漏的返回路径。

## 示例与实践

### 1. 可运行的综合示例：成绩统计与菜单

下面的程序使用 `if...else` 判断成绩等级，使用 `for` 计算平均分，使用 `switch` 处理菜单，并演示 `break`、范围 `for` 和输入校验。将代码保存为 `basic_control_flow.cpp`。

~~~cpp
#include <iostream>
#include <vector>

// 根据分数返回等级。调用者应传入 0 到 100 之间的分数。
char grade_of(int score) {
    if (score >= 90) {
        return 'A';
    } else if (score >= 80) {
        return 'B';
    } else if (score >= 60) {
        return 'C';
    }
    return 'D';
}

int main() {
    std::vector<int> scores;
    std::cout << "请输入 3 个 0 到 100 之间的成绩。\n";

    // 反复读取，直到得到三个合法成绩
    while (scores.size() < 3) {
        int score{};
        std::cout << "第 " << scores.size() + 1 << " 个成绩：";

        if (!(std::cin >> score) || score < 0 || score > 100) {
            std::cout << "输入无效，请输入整数 0 到 100。\n";
            std::cin.clear();
            std::cin.ignore(10000, '\n');
            continue; // 本轮失败，重新读取，不把错误值放入 vector
        }
        scores.push_back(score);
    }

    int sum = 0;
    for (int score : scores) {
        sum += score;
    }
    const double average = static_cast<double>(sum) / scores.size();

    std::cout << "\n成绩：";
    for (int score : scores) {
        std::cout << ' ' << score;
    }
    std::cout << "\n平均分：" << average << '\n';

    char command{};
    do {
        std::cout << "输入命令 [g=查看等级, q=退出]：";
        std::cin >> command;

        switch (command) {
        case 'g':
            for (int score : scores) {
                std::cout << score << " 分 -> " << grade_of(score) << '\n';
            }
            break;
        case 'q':
            std::cout << "程序结束。\n";
            break;
        default:
            std::cout << "未知命令。\n";
            break;
        }
    } while (command != 'q');
}
~~~

.\basic_control_flow.exe
~~~
